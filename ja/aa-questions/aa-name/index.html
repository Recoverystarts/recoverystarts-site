アルコホーリクス・アノニマスという名前はどのようにつけられたのですか？「The Way Out」が題名だったのですか？

このページのAAの文献からの引用のうち、12のステップ、12の伝統（短いものと長文のもの）、12の概念の短いかたち、AAの序文は、AA日本ゼネラルサービス（JSO）が公開している日本語です。ビッグブックの本文、祈り、12の概念の長いかたち、そのほかのAAの文献や歴史書からの引用の日本語は、AAの英語の原文からの私たちの翻訳で、AAが出版した日本語訳ではありません。英語で読む

ひとことで言うと：

  • 1939年まで、共同体には名前がありませんでした。名前は本の題名、『アルコホーリクス・アノニマス』からきており、共同体は「自分たちの本の題名にちなんで、アルコホーリクス・アノニマスと呼ばれ始めた」のです（xviiページ）。
  • 「The Way Out」（「出口」）は、もうひとつの有力な候補でした。ビル・Wの記述によれば、アクロンとニューヨークのグループが投票を行い、「The Way Out」がわずかな差で勝ちました。そのあとフィッツ・Mが米国議会図書館で調べると、「The Way Out」という題の本がすでに何冊もあり、「Alcoholics Anonymous」という題の本は1冊もないことがわかりました。メンバーは、またひとつ増える「way out」になりたくなかったのです。そのため、「The Way Out」が本の出版された題名になることは一度もありませんでした。
  • ビルは、「アルコホーリクス・アノニマス」という言葉を最初に使ったのが誰なのか、誰も知らないと言います。彼は、この言い回しは、ニューヨークの人たちが自分たちのことを「名もないアルコホーリクの集まり」と呼んでいたことから生まれたと考えていました。のちの本は、文書で使われた例を1938年なかばまでさかのぼり、1937年にはすでにあったと述べる本もあります。
  • 資料は、細かい点で食い違っています。検討された題名がいくつあったのか、フィッツが何冊の本を見つけたのか、です。

1939年のビッグブック

「初版に寄せて」は、すでにこの名前を本だけでなく人びとに対しても使っています。「私たちアルコホーリクス・アノニマスは、百人を超える男女である」（xiiiページ）。また、公の場で書いたり話したりするメンバーには名前を伏せるよう求め、「かわりに『アルコホーリクス・アノニマスのメンバー』と名乗る」ようにとしています（xiiiページ）。署名は「アルコホーリクス・アノニマス」です（xivページ）。本自身は、この名前がどのように選ばれたかを語っていません。「初版に寄せて」は、AAは何のためにあると述べていますか？もご覧ください。

「再版にあたって」（1955年）：「まだ名前のなかったこの生まれたばかりの会は、このころから、自分たちの本の題名にちなんで、アルコホーリクス・アノニマスと呼ばれ始めた。」（xviiページ）。

ビルの最初の記述（1946年）

アノニミティについての1946年のグレープバイン誌の記事（P-17に再録）のなかで、ビルは、本ができる前は「私たちには名前がなかった」（P-17、1946年）と書いています。「私たちは少なくとも200の題名を検討したに違いない。」（P-17、1946年）。選択肢は「The Way Out」か「Alcoholics Anonymous」に絞られ、アクロンとニューヨークのグループによる土壇場の投票は、わずかな差で「The Way Out」に傾きました（P-17、1946年）。そこで、「当時ワシントンに住んでいた」フィッツ・Mが、米国議会図書館へ行きました。「彼は、すでに『The Way Out』という題がついた本が、ちょうど12冊あることを見つけた。」（P-17、1946年）。「この情報が伝わると、私たちは、13番目の『Way Out』になってしまうかもしれないと思って身震いした。」（P-17、1946年）。「こうして、私たちの経験の本に名前がつき、私たちの運動にも名前がついた」（P-17、1946年）。そしてビルは、アノニミティの伝統もそこから生まれた、と付け加えています。

ビルのより詳しい記述（『アルコホーリクス・アノニマス 成年に達する』、1957年）

ビルは、複製した貸出用の写しに「アルコホーリクス・アノニマス」と書いていましたが、それでもこの題名を気に入らない人は多くいました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。その名前は「おそらく1938年10月に」現れたといいます（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「私たちは、誰がこの言葉を最初に使ったのか知らない。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。1937年にオックスフォード・グループを離れたあと、ニューヨークの人たちはしばしば自分たちを「名もないアルコホーリクの集まり」と呼んでおり（『アルコホーリクス・アノニマス 成年に達する』、1957年）、名前はその言い回しから来たのだと彼は言います。

彼は、ある誘惑を打ち明けています。「The Way Out」にすれば、本に自分の名前を署名できるのです。そして彼は、友人たちにたしなめられる前に、「The B. W. Movement」（B・W運動）と呼ぶことまで考えました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「私たちは全部で100を超える題名を検討した。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ニューヨークは、ジョー・Wという書き手に励まされて「アルコホーリクス・アノニマス」に傾き、アクロンは「The Way Out」を支持して、全体ではぎりぎりの過半数を占めました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルはメリーランドの農場にいたフィッツに電報を打ち、米国議会図書館で調べてもらいました。「The Way Out」という題の本は12冊、「Alcoholics Anonymous」という題の本は1冊もありませんでした（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「この本を13番目の『Way Out』にするわけにはいかない。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「そうして私たちの本の題名が決まり、そうして私たちの共同体の名前が決まったのだ。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

のちの記述（1980年、1984年）

  • 『ドクター・ボブと古き良き仲間たち』（1980年）は、アクロンでは、ヤコブの手紙（Book of James）がとても好まれていたため、「『ジェームズ・クラブ』を共同体の名前にすることを推す人もいた。」と述べています（『ドクター・ボブと古き良き仲間たち』、1980年）。また、1938年6月のビルの手紙を引いています。そこでビルは、ドクター・ボブにこう尋ねました。「たとえば、アルコホーリクス・アノニマスという名の慈善団体をつくることについて、どう思いますか？」（『ドクター・ボブと古き良き仲間たち』、1980年）。ほかに提案された題名として「A Way Out」や「Comes the Dawn」などを挙げ、その名前はすでに限られた範囲で使われていて、「それに触れたものは、早くも1937年に見つけることができる」と述べています（『ドクター・ボブと古き良き仲間たち』、1980年）。アクロンのある妻は、「それは、いままで聞いたなかでいちばんひどい名前だ、と思ったのを覚えている。」と語っています（『ドクター・ボブと古き良き仲間たち』、1980年）。
  • 『Pass It On』（1984年）は、多くの人がこの名前をつくったのはジョー・Wだと考えていた（『Pass It On』、1984年）としながらも、「AAの記録保管所で、この名前が文書で使われた最初の記録は、フランク・エイモスからアルバート・スコットへの1938年6月24日付の手紙にある。」（『Pass It On』、1984年）と述べています。そこでは、本は特定の著者ではなく「アルコホーリクス・アノニマス」によるものとされていました（『Pass It On』、1984年）。ほかの題名として「One Hundred Men」、「The Empty Glass」、「Dry Frontiers」などを挙げ、「One Hundred Men」は、ただひとりの女性メンバーが反対したため取り下げられたと述べています（『Pass It On』、1984年）。また、本の編集者トム・アゼルは、「アルコホーリクス・アノニマス」が正しい題名だと強く主張した、とも述べています（『Pass It On』、1984年）。

資料の記述が食い違うところ

  • 題名の数。「少なくとも200」（P-17、1946年）、「100を超える」（『アルコホーリクス・アノニマス 成年に達する』、1957年；『Pass It On』、1984年）。
  • フィッツが見つけたもの。「The Way Out」という題の本が12冊（P-17、1946年；『アルコホーリクス・アノニマス 成年に達する』、1957年）。『Pass It On』は、フィッツが「電報で返事をしたとされている」と述べ、その内容は、米国議会図書館には「『The Way Out』という題の本が25冊、『The Way』という題の本が12冊、そして『Alcoholics Anonymous』という名の本は1冊もない」というものでした（『Pass It On』、1984年）。その電報は、私たちが読んだ資料にはありません。
  • フィッツがいた場所。「当時ワシントンに住んでいた」（P-17、1946年）、「メリーランドの農場に」（『アルコホーリクス・アノニマス 成年に達する』、1957年）、「ワシントンD.C.の近くに」（『Pass It On』、1984年）。
  • 名前が最初に現れた時期。ビル（1957年）：おそらく1938年10月（『アルコホーリクス・アノニマス 成年に達する』、1957年）。『Pass It On』：記録に残る最初は1938年6月24日（『Pass It On』、1984年）。『ドクター・ボブと古き良き仲間たち』：早くも1937年には言及があるとしていますが（『ドクター・ボブと古き良き仲間たち』、1980年）、その例は引いていません。
  • 名前をつくったのは誰か。ビルは、誰も知らないと言います（『アルコホーリクス・アノニマス 成年に達する』、1957年）。『Pass It On』は、多くの人がジョー・Wの名を挙げていたと伝えています（『Pass It On』、1984年）。私たちが読んだ資料では決着がつきません。
  • どのグループが最初にその名前を名乗ったかについては、クリーブランドのグループは、どのようにして初めて「アルコホーリクス・アノニマス」を名乗るグループになったのですか？をご覧ください。

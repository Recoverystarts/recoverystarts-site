1939年より前に、ビッグブックの草稿はありましたか？

このページのAAの文献からの引用のうち、12のステップ、12の伝統（短いものと長文のもの）、12の概念の短いかたち、AAの序文は、AA日本ゼネラルサービス（JSO）が公開している日本語です。ビッグブックの本文、祈り、12の概念の長いかたち、そのほかのAAの文献や歴史書からの引用の日本語は、AAの英語の原文からの私たちの翻訳で、AAが出版した日本語訳ではありません。英語で読む

ひとことで言うと：

  • はい。ビル・Wは1938年を通して章を書き、ニューヨークのグループに読み聞かせ、コメントを求めてアクロンのドクター・ボブに送りました。最初の二つの章は、1938年なかばに、資金集めの趣意書に使うために複写されました。
  • 本文と物語が完成した1939年1月末ごろ、本全体の写し400部が複製され、コメントを求めて送られました。それぞれに「Loan Copy」（貸出用の写し）のスタンプが押されていました。ビルはそれをミメオグラフ（謄写版）と呼び、のちの本はマルチリス（Multilith）の写しと呼んでいます。
  • コメントは本を変えました。ある精神科医はビルを説得して「you must」（あなたは～しなければならない）を「we ought」（私たちは～すべきだ）に変えさせ、カトリックの委員会は、ビルの物語の終わりの「Heaven」（天国）を「Utopia」（ユートピア）にするよう提案し、ビルの印刷用の原稿は、小さな訂正がたくさん書き込まれた貸出用の写しでした。1984年の伝記は、プロの編集者が原稿を少なくとも3分の1削ったとも述べています。
  • 私たちが読んだ資料には、どの草稿の写しも含まれていないため、これらの報告された変更のほかに、以前の版が何と書いていたかを示すことはできません。

ビッグブック自身が示していること

本は、自らの改訂について、出版後にのみ触れています。付録IIは「最初の印刷は、多くの読者にこういう印象を与えた」（567ページ）、つまり霊的体験は突然で劇的でなければならないという印象を与えたと述べ、それを正すために加えられました。今日の本の「初版に寄せて」は、「1939年の初版の最初の印刷に載ったとおりに」印刷されています（xiiiページ）。ビルの物語はこう終わります。「私たちの多くは、もはやユートピアを探す必要はないと感じている。」（16ページ）。この言葉は、カトリックの査読者が提案したものです（下を参照）。ビッグブックの4つの版のあいだで、何が変わりましたか？もご覧ください。

作業中の草稿（1938年）

ビルは1938年の春に本を書きはじめました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。資金集めの運動が始まるころには、彼は自分の物語を書き上げ、第2章の下書きを仕上げていました。「この二つの章のミメオグラフの写しは、資金集めの活動のための道具立ての一部だった」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。P-44（ビルが1955年までの出来事を述べたもの）も同じことを述べています。二つの章の写しは「趣意書の一部として使われた」（P-44）。ハーパー社の編集者がその二つの章を読んで、出版を申し出ました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビッグブックの費用はどう工面され、どのように出版されたのですか（ワークス・パブリッシング）？をご覧ください。

ビルは秘書のルース・ホックに荒い草稿を口述し、毎週のニューヨークのミーティングで各章を読み上げ、写しをアクロンのドクター・ボブに送りました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ニューヨークでは、章は「手ひどく叩かれ」、彼は何度も口述し直しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。アクロンについては、『ドクター・ボブと古き良き仲間たち』（1980年）によると、あるメンバーは「選ばれた少数」のひとりとしてドクター・ボブと草稿に目を通したことを覚えており、別のメンバーは、草稿がアクロンのミーティングで読まれたことを覚えています（『ドクター・ボブと古き良き仲間たち』、1980年）。

400部の貸出用の写し（1939年初め）

本文と物語が1939年1月末に完成したとき、誰かが尋ねました。「この本が誰にでも広く受け入れられるかどうか、どうすれば確かにわかるのか？」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。そこで「本のミメオグラフの写しが400部つくられ、アルコホリズムの問題に関わりのありそうな、思いつくかぎりの人すべてに送られた。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「それぞれのミメオグラフには、これから取る著作権を守るために『Loan Copy』のスタンプが押された。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。待っているあいだにも、題名と12のステップをめぐる議論は続いていました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

返ってきたもの（『アルコホーリクス・アノニマス 成年に達する』、1957年）：

  • モントクレアの精神科医ハワード博士は、「私たちの本の本文は、『あなた』と『しなければならない』という言葉であふれすぎていると指摘した」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ねらいは「私たちの共同体を、『あなたはしなければならない』ではなく『私たちはすべきだ』を基調とするものにすること」でした（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルは譲り、シルクワース医師とティボウト博士も同様の助言をしました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • ハリー・エマーソン・フォスディック博士は1939年の初めに出版前の見本を見て、書評を約束しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • ニューヨークのカトリック出版委員会は、黙想と祈りの部分の改善と、ビルの物語の最後にある一つの実質的な変更を提案しました。「ビル・Wは、その『天国』という言葉を『ユートピア』に変えてはどうだろうか？」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

印刷用の原稿は、ヘンリー・Pがすべての訂正を書き込んだミメオグラフの一部でした（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「大きな変更は少なかったが、小さな変更は非常に多かった」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

貸出用の写しの一部は、その後も働きつづけました。ティーボート医師は、患者のマーティにそれを一部渡し、マーティは二度読んだあとでミーティングにやって来ました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルはクリーブランドの弁護士に一部渡し、その依頼人がそれを読んでアクロンへ行きました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。『ドクター・ボブと古き良き仲間たち』によれば、あるメンバーの妹が「ビッグブックのマルチリスの写しを持ってシカゴへ行き」（『ドクター・ボブと古き良き仲間たち』、1980年）、それが、そこにいた女性メンバーにつながりました。

『Pass It On』（1984年）

『Pass It On』は、最初の2章が1938年の資金集めのために「ただちにマルチリス印刷された」と述べ（『Pass It On』、1984年）、「1939年1月の終わりまでに、原稿は事前配布の準備ができ、400部がマルチリス印刷された」と述べています（『Pass It On』、1984年）。さらに、ビルの1957年の記述にない細部を加えています：

  • 「医師の意見」は、ジョンズ・ホプキンスのエスター・リチャーズ博士が、一流の医師による序文を提案したあとに加えられました（『Pass It On』、1984年）。「医師の意見」とは何で、誰が書いたのですか？もご覧ください。
  • ニューヨーク大学のトム・ウゼルが「本の最終的な編集を行い」、「本を少なくとも3分の1削った」（『Pass It On』、1984年）、「半分だと言う人もいる」ほどで、800ページから400ページになりました（『Pass It On』、1984年）。
  • 第5章の、いまは「私たちの道をたどった」となっている一文は、以前の原稿では「指示」となっていました（『Pass It On』、1984年）。

資料の記述が食い違うところ

  • ミメオグラフか、マルチリスか。ビル（1957年）とP-44は、ミメオグラフ（謄写版）と述べ（『アルコホーリクス・アノニマス 成年に達する』、1957年；P-44）、『Pass It On』と『ドクター・ボブと古き良き仲間たち』は、マルチリスと述べています（『Pass It On』、1984年；『ドクター・ボブと古き良き仲間たち』、1980年）。どちらも複製の方法であり、部数の400は一致しています。
  • どれだけ削られたか。ビル（1957年）は、多くの小さな訂正にしか触れていませんが（『アルコホーリクス・アノニマス 成年に達する』、1957年）、『Pass It On』は、外部の編集者による3分の1以上の削減を伝えています（『Pass It On』、1984年）。私たちが読んだ資料には、どちらも確かめられる草稿がありません。
  • 以前の文面。私たちが読んだ資料が伝えている以前の文面は、「Utopia」の代わりの「Heaven」（『アルコホーリクス・アノニマス 成年に達する』、1957年）、「we ought」の代わりの「you must」（『アルコホーリクス・アノニマス 成年に達する』、1957年）、「path」の代わりの「directions」（『Pass It On』、1984年）、そして再構成されたステップの最初の草稿（12のステップはどのように書かれたのですか？をご覧ください）だけです。出版前の原稿のほかの箇所についての主張は、私たちが読んだ資料からは確認できません。

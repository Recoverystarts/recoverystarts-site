エド・ダウリング神父とはどんな人で、なぜAAの歩みに登場するのですか？

このページのAAの文献からの引用のうち、12のステップ、12の伝統（短いものと長文のもの）、12の概念の短いかたち、AAの序文は、AA日本ゼネラルサービス（JSO）が公開している日本語です。ビッグブックの本文、祈り、12の概念の長いかたち、そのほかのAAの文献や歴史書からの引用の日本語は、AAの英語の原文からの私たちの翻訳で、AAが出版した日本語訳ではありません。英語で読む

ひとことで言うと：

  • エドワード・ダウリング神父（イエズス会）は、セントルイスのイエズス会の司祭で、カトリックの雑誌『The Queen's Work』のスタッフの一員でした。ビル・Wは、彼をAAの、宗教に関わる非アルコホーリクの友人たちの一人に数えています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビッグブックは付録V「AAに対する宗教界の見解」で彼を引用しており（英語版572ページ）、その脚注は彼を「AAの初期の、すばらしい友人」と呼び、1960年の春に亡くなったと述べています（572ページ）。
  • ビル・Wは、彼がAAの知るかぎり最初のカトリックによるAAの推薦（1940年）をしたこと、セントルイスで最初のAAグループの立ち上げを助けたこと、そして12のステップが聖イグナチオの霊操に似ていることに、彼の信仰をもつ人として最初に気づいたことを、彼の功績として挙げています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • 彼はビルの生涯の友人であり助言者になりました。お金についての彼の助言によって、共同創始者たちがプロにならずに報酬を受け取る方法が定まりました：十二番目のステップ活動に対しては決して受け取らず、本の印税は受け取る、というものです（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • 彼は、自分の故郷の街で開かれた1955年のセントルイス大会で話しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

ビッグブックのなかで（1955年の付録）

付録Vはこう始まります：「ほとんどあらゆる宗派の聖職者が、AAに祝福を与えてくれた。」（英語版572ページ）。最初に引用されているのは「『Queen's Work』スタッフのエドワード・ダウリング、S.J.」（572ページ）です。彼は、AAは「自然なものである。自然が超自然にもっとも近づくところ、すなわち屈辱と、その結果としての謙虚さにおいて、自然なものである。」（572ページ）と述べています。彼はそれを、美術館や交響曲、カトリック教会が認める「何か霊的なもの」をそなえたものになぞらえ、「それにカトリック信者が参加すると、ほとんどいつも、出来の悪いカトリック信者がよりよいカトリック信者になる。」と結んでいます（572ページ）。同じページに、聖公会の雑誌『The Living Church』とハリー・エマーソン・フォスディック博士も引用されています（572ページ）。

付録は第2版で本に加えられました（英語版xiページ）。1960年の彼の死についての脚注は、さらにあとから加えられたものです。1939年の本文には彼への言及はありません。参照：付録V「AAに対する宗教界の見解」には何が書かれていますか？ · AAは宗教団体ですか？

彼がAAに加わった経緯（ビルの記述、1955～57年）

ビルは、これを『アルコホーリクス・アノニマス 成年に達する』（1957年）で語っています。1940年の冬のある夜、ビルはニューヨークのウェスト24丁目にあったAA最初のクラブハウスで早く寝床に入りました、「ひどい自己憐憫と想像上の胃潰瘍を抱えて」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。みぞれが屋根を打っていました。管理人のオールド・トムが上がってきて、セントルイスから「どこかの浮浪者」が会いに来たと告げました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。訪ねてきた人は杖をついて階段を上がってきて、外套を開いたとき、ビルは聖職者の襟を見ました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

「私たちはいろいろなことを話し、私の気持ちはどんどん上向いていった」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルは、その人が「その場を臨在の感覚で満たす恵みを放っていた」と述べ（『アルコホーリクス・アノニマス 成年に達する』、1957年）、その後の年月、喜びのときも痛みのときも、エド神父はいつも彼に「同じ恵みの感覚と神の臨在」をもたらしてくれたと述べています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

彼がAAのためにしたこと

ビルはこれらを、「AAの新しい世代が聞き、読み、知っておくべき事実」として書き記しています（『アルコホーリクス・アノニマス 成年に達する』、1957年）：

  • 最初のカトリックによる推薦。彼は「イエズス会の創設者である聖イグナチオの霊操と、12のステップのあいだの驚くべき類似に気づいた、彼の信仰の最初の聖職者」であり（『アルコホーリクス・アノニマス 成年に達する』、1957年）、そのため1940年に、「私たちの知るかぎり、最初のカトリックによるAAの推薦」を書きました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。その最初の記事は、信心会の雑誌『The Queen's Work』に載りました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルはその趣旨を「みなさん、AAはいいものです。さあ、受け取りに来てください。」とまとめ（『アルコホーリクス・アノニマス 成年に達する』、1957年）、「実質的には」と言っています：それはビルによる言い換えであって、引用ではありません。
  • セントルイスのAA。彼は「この街で最初のAAグループの立ち上げを助けた」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルは、そのグループが主にプロテスタントの人たちになったが、それは彼を「少しも動揺させなかった」と記しています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • 長年の働き。「旅、AAのミーティング、賢く優しい助言」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。そして1955年の聴衆の多くが、霊的な必要に応えてくれた彼の働きを覚えていました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。この本の1940年の画期的な出来事には、「宗教指導者がAAを承認。ダウリング神父、フォスディック博士」とあります（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

お金についての助言（1941年3月以降）

ここは、彼がAAの働き方を形づくった場面で、ビルはその全体を語っています。ビルは日付を示していません：1941年3月1日の『サタデー・イブニング・ポスト』誌の記事のあとで、「1942年の初め」の出来事の直前に語っています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。『サタデー・イブニング・ポスト』誌の記事のあと、ある街では、本とニューヨークの事務所は詐欺だといううわさが立ちました。監査の結果、ビルが週55ドルで暮らしており、ドクター・ボブは印税を一度も受け取っていないことがわかりました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。それでもビルは、そもそも何かを受け取るべきかどうか決められませんでした。「財務調査の一件の少しあと、セントルイスから来た私たちのイエズス会の友人、エド・ダウリング神父」が、ニューヨークに来て、ビルは彼にこの件を相談しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

エド神父は、AAがビルをフルタイムで必要としているか（はい）、そしてビルが十二番目のステップ活動でお金を受け取れるかを尋ねました。ビルは、それはとうの昔に決着していると答えました：受け取れない、「ほかのどのAAメンバーも受け取れない」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。そして：ビルだけの問題なら何も受け取らずにすむが、「しかしロイスはどうなる？」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルには、彼女を養うという結婚契約があり、エド神父は、印税が「最善の策」だろうと考えました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

ビルの結論：「ドクター・ボブと私は、十二番目のステップ活動に対しては決してお金を受け取ってはならないが、特別なサービスに対しては報酬を受けてよい。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「私たちは二人とも、エド神父の中道の助言を受け入れ、それ以来ずっと守ってきた」（『アルコホーリクス・アノニマス 成年に達する』、1957年）、そしてビルは、のちに共同体全体がそれを原則として正しいと受け入れたと述べています。彼はこの出来事を、職業化についての伝統が生まれた試金石となった事例のひとつに数えています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。参照：伝統8：十二番目のステップ活動で報酬を受け取ってよい人はいますか？

1955年、セントルイスで

20周年記念大会は、彼の街で開かれました。日曜朝のミーティング「自分なりに理解した神」で、「エド・ダウリング神父が、ひどい足の不自由もものともせず演台へ歩み出ると、大きな歓迎の歓声が上がった。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルは彼を紹介しました：「エド神父は、聖人と同じ素材でできている。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。そして、彼から恨みの言葉を聞いたことが一度もない、自分が知る唯一の人だと述べました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

彼の講演は全文が掲載されており（『アルコホーリクス・アノニマス 成年に達する』、1957年）、大会の三つの言葉、「神」「私たち」「理解」を取り上げています。その一部を、彼自身の言葉で：

  • アルコホーリクについて：「私たちには、恥という途方もない原動力がある。それは無垢にいちばん近いものである。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • メンバーがどのようにやって来るかについて：「この会場に、本当にソブラエティを求めた人が誰かいるとは思えない。私たちは、酔っぱらうことから逃れようとしていたのだと思う。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • 神を理解することについて：「私たちの神の観念は、いつも不十分だろう」（『アルコホーリクス・アノニマス 成年に達する』、1957年）が、理解は深まっていくと述べています。
  • 彼は、手元に取っておいたビルの手紙を引いています。アルコホーリクが神への依存をどこまで突き詰めるかは、教会の内であれ外であれ、「AAの関知するところではない」（『アルコホーリクス・アノニマス 成年に達する』、1957年）と述べた手紙です。
  • 続いて、キリスト教徒として「キリスト教が私に教えてくれたとおりの、人に向けた神の12のステップ」（『アルコホーリクス・アノニマス 成年に達する』、1957年）を述べ、フランシス・トンプソンの「天の猟犬」（『アルコホーリクス・アノニマス 成年に達する』、1957年）で締めくくっています。

彼の講演は友人としての語りかけであり、AA文献の教えではありません：彼はカトリックの司祭として率直に語っています。そのあとに続いたサム・シューメーカー博士は、その講演が「理論と神学」を人々それぞれが属する教会に委ねたと述べました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルが描く大会参加者の合成像「グラスルーツ氏」は、エド神父とサム博士の話を聞いて、AAの霊的な原理の大半が聖職者たちを通してもたらされたことに気づいたと語ります（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルはグラスルーツ氏を、大会全体を代弁する「一種の合成された人物」として紹介しており、実在の人物ではありません（『アルコホーリクス・アノニマス 成年に達する』、1957年）。参照：1955年のセントルイス大会では何があったのですか？

慎重に扱う後年の記述（1984年）

『Pass It On』（1984年）はビルの伝記で、手紙とのちの記憶から、さらに多くを伝えています：

  • 最初の訪問は「1940年の暮れ近い、寒い雨の夜」のことだったとし、司祭の最初の言葉についてのビルの記憶を引いています：「セントルイスから来たダウリング神父です。」（『Pass It On』、1984年）。そこのイエズス会士たちは、本『アルコホーリクス・アノニマス』に目を通していたと、彼は述べました（『Pass It On』、1984年）。
  • ビルがのちにあの夜を、第5ステップを行った夜であり、「第二の回心体験」（『Pass It On』、1984年）と呼んだと述べ、二人の友情を、手紙で続けられた20年にわたる「霊的スポンサーシップ」だとしています（『Pass It On』、1984年）。エド神父がビルの落ち着かなさを「神聖な不満」と表現したことも語られています（『Pass It On』、1984年）。ビル自身の1957年の記述には、これらの言葉はありません。参照：ステップ5は、誰に話せばよいですか？
  • ビル個人にとっては、1955年の大会の開催地セントルイスには、「霊的スポンサーであるダウリング神父の故郷」であるという利点も加わっていた、と述べています（『Pass It On』、1984年）。
  • ビルが彼に宛てたカトリック教会についての手紙を引いており（ビルはカトリックの教えを受けたが、教会には入らなかった）（『Pass It On』、1984年）、ビルが『アルコホーリクス・アノニマス 成年に達する』でオックスフォード・グループの功績を認める前に彼に相談したと述べています（『Pass It On』、1984年）。

これらは、私たちの資料にはない手紙を、のちの本が読み取ったものです。日付が特定されたものであり、ビル自身の記述の一部ではありません。

出典だけでは決まらないこと

  • 最初の推薦と最初の訪問の年。ビル（1957年）は、どちらも1940年だったと述べています。ビッグブックの付録は、引用に日付を付けておらず、私たちの資料には『Queen's Work』の記事の写しがありません。
  • 足が不自由になった原因。ビルはそれを「ひどい足の不自由」と呼び、『Pass It On』は彼を「体が不自由」と呼んでいますが、どちらも理由は述べていません。
  • 彼の生没年。私たちの資料には彼の死（1960年春、英語版572ページ；『アルコホーリクス・アノニマス 成年に達する』、1957年、のちの脚注）はありますが、生年はありません。

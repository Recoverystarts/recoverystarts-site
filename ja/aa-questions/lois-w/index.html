ロイス・Wとは誰で、AAの始まりで何をしましたか？

このページのAAの文献からの引用のうち、12のステップ、12の伝統（短いものと長文のもの）、12の概念の短いかたち、AAの序文は、AA日本ゼネラルサービス（JSO）が公開している日本語です。ビッグブックの本文、祈り、12の概念の長いかたち、そのほかのAAの文献や歴史書からの引用の日本語は、AAの英語の原文からの私たちの翻訳で、AAが出版した日本語訳ではありません。英語で読む

ひとことで言うと：

  • ロイス・Wは、ブルックリンのロイス・バーナムで、1918年1月24日にビル・Wと結婚し（P-53、2017年）、彼の飲酒の時期もそばを離れず、1988年10月5日に亡くなりました（『Pass It On』、1984年、のちの刷りの年表）。ビッグブックは彼女の名前を挙げていません。「ビルの物語」（1939年）では、彼が飲んでいるあいだ百貨店で働いた「私の妻」として登場します（英語版4ページ）。
  • AAの最初の数年、彼女は家計を支え、アルコホーリクたちに自宅を開きました。「妻と私は、他のアルコホーリクを助けるという考えに、熱意をもって身をゆだねた」（英語版15ページ）。1935年の秋から、ニューヨークで最初のミーティングが、ブルックリンの二人の居間で開かれました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • 彼女と、アクロンのアン・スミスは、最初からアルコホーリクの妻や夫に12のステップを勧めていました。ビルは、「アン、ロイス、ケイティが、はるか昔にその考えの種をまいた」ものが、アラノン家族グループに育ったと書いています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。私たちの資料には、彼女がアラノンを創設したとは、そのままの言葉では書かれていません。
  • 1955年のセントルイスで、彼女は閉会のセッションで、家族を代表して話しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルは彼女を「希望が失われたときも、揺るがず耐え抜いた人」と呼びました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

ビッグブック（1939年）では

「ビルの物語」（英語版1～16ページ）は彼女の名前を一度も挙げていませんが、ほとんどのページに彼女がいます。若い夫婦は1,000ドルを貯め、いっしょにオートバイで工場を回りました（2ページ）。1929年の大暴落のあと、二人は「妻の両親」のもとで暮らしました（4ページ）。「私の妻は百貨店で働き始め、くたくたになって帰ってくると、酔った私を見ることになった。」（4ページ）。いちばんひどい時期には、彼は「妻の乏しい財布から」盗みました（6ページ）。章の終わりでは、二人でその仕事に取りかかります。「妻と私は、他のアルコホーリクが問題の解決にたどり着けるよう助けるという考えに、熱意をもって身をゆだねた。」（15ページ）。

それが1939年の本文が描く彼女のすべてです。持ちこたえた妻、そして仕事の協力者。第8章「妻たちへ」は、メンバーの妻たちの声で書かれていますが、ビッグブックは誰が書いたかを述べていません。歴史書は、ビルが書いたこと、ロイスは頼まれなかったことを述べています（下を参照）。次もご覧ください：ビッグブックの各章は、「妻たちへ」も含めて、誰が書いたのですか？

彼女の人生の事実

  • 結婚。P-53（©2017）は一行で述べています。「ビルは、現役の任務に就く少し前の1918年1月24日に、ニューヨーク州ブルックリンのロイス・バーナムと結婚した。」（P-53、2017年）。『Pass It On』（1984年）は、結婚式は2月1日に予定されていたが、ビルが海外へ送られるかもしれなかったため前倒しされたと述べています（『Pass It On』、1984年）。1955年の講演でビルは、「そこへロイスが現れて、私は突然、再び生き返った」と語っています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • 飲酒の年月。P-53は、1931年までに飲酒は深刻な問題になっていたと述べ、それは「ロイスの努力と、彼女にした飲酒をやめるという多くの約束や誓いにもかかわらず」だったとしています（P-53、2017年）。1934年には、タウンズ病院でシルクワース医師の診断を聞いたのは彼女でした。ビルは、彼女が彼には「とてつもない意志の力」があると抗議し、なぜやめられないのかと尋ねたと語っています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。休戦記念日の再飲酒の翌朝、彼女は、自宅の脇の窪んだ通路で意識を失っている彼を見つけました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。『Pass It On』は、1933年のメイシーズでの彼女の給料を、週22.50ドルに歩合を加えた額としています（『Pass It On』、1984年）。
  • 彼女の死。私たちが所蔵する『アルコホーリクス・アノニマス 成年に達する』の復刻版に加えられた年表には、彼女の死が10月5日と記録され（『アルコホーリクス・アノニマス 成年に達する』、のちの復刻版）、『Pass It On』の年表は1988年10月5日としています（『Pass It On』、1984年、のちの刷り）。ビルは、二人の結婚53周年にあたる1971年1月24日に亡くなりました（『Pass It On』、1984年）。

最初の数年に彼女がしたこと（ビルの記述、1955～57年）

ビル自身のAAの歴史は、彼女の名前を何度も挙げ、たいていは、二人に家と食べ物を与え続けた人として書いています：

  • 家計を支える人。1935年、ビルの霊的体験のあとも、「そのあいだロイスはまだ百貨店で働いていた」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。1937年には、「ロイスはまだ百貨店にいて、その給料が私たちのもっているお金のほとんどすべてだった」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。その間、何人かのアルコホーリクが二人と暮らし、ほとんどは下宿代を払いませんでした。
  • クリントン・ストリート182番地の家。ビルが1935年の秋にアクロンから戻ると、ロイスは「クリントン・ストリートの古い実家をアルコホーリクでいっぱいにしたら、すばらしいだろうと考えた」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。期待どおりにはいきませんでした。ビルは、そこに住んだ人たちのうち、ひとりも飲まないようにさせられなかったが、多くを学んだと述べています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。同時に5人が家にいたこともあり、そこにひとりで残された男性が自ら命を絶ちました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。彼女とビルは、そこから「もしアルコホーリクに私たちへの依存が強くなりすぎるのを許せば、彼らは酔ったままでいがちだ」と学びました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。その間、その秋に二人の居間で毎週のミーティングが形になり、ニューヨークのグループの始まりとなりました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。セントルイスでは、「ロイスは、3年間、クリントン・ストリートの私たちの家が、地下室から屋根裏部屋まで、あらゆる種類のアルコホーリクでいっぱいだったことを振り返った」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • 家を失う。1939年5月1日、ビッグブックが出たものの売れなかった直後、二人は彼女の両親のものだった家を出なければなりませんでした。銀行がその家を引き取り、二人に名目だけの賃料で貸していましたが、そこに買い手がついたのです（『アルコホーリクス・アノニマス 成年に達する』、1957年）。P-44には、ビルによる説明があります。「彼女と私は通りへ放り出され、それからAAの友人たちの善意にすがることになった。」（P-44）。小さな基金が設けられました。理事会が最初に得たお金で、「ロイス・Wの住まい再建基金」と呼ばれ、そこから理事たちが夫妻に月50ドルを払いました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。二人は借り物の夏の別荘で暮らし、それからニューヨーク州モンジーの友人宅で冬を過ごし、その後、AA最初のクラブハウスがあるウェスト24丁目の、2階の小さな部屋に住みました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルは、本の見通しがもっとも明るく見えたときに彼女を説得して百貨店の仕事を辞めさせたこと、そして1939年の夏までに、彼女は仕事を続けるべきだったのではないかと考え始めていたことを付け加えています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。
  • お金と結婚の誓い。ビルが本の印税を受け取るかどうか決められなかったとき、エド・ダウリング神父は彼に、「だが、ロイスのことはどうなのか？」とたずね（『アルコホーリクス・アノニマス 成年に達する』、1957年）、彼女を養うと約束していたことを思い出させました。ビルは印税を受け取りました。何年もあと、彼はセントルイス大会で、印税が「ロイスと私に家を与えてくれ、その家で私たちはこれまでの歳月に3,000人以上の皆さんに会ってきた」と語りました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。次もご覧ください：エド・ダウリング神父とはどんな人で、なぜAAの歩みに登場するのですか？
  • 旅。1950年、二人は海外のAAグループを訪ねる6週間の旅をしました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。『Pass It On』は、二人が各地のグループを回る最初の全国横断旅行を1943年としています（『Pass It On』、1984年）。

ロイスと家族グループ

これが、彼女がもっともよく記憶されていることですが、いちばん古い資料はこれについて慎重です。

1957年、ビルは、シカゴのメンバーの妻であるケイティが、「アンとロイスがすでにつくっていた前例」を受け継いだと書いています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。アンとロイスは、自宅で、旅先で、24丁目のクラブの2階で、アルコホーリクではない妻や夫に、「家庭生活を正常に戻す方法として」AAの12のステップを勧めていました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルは、最初の家族グループがいつ始まったのか、正確には誰も知らないと述べ、初期のものとしてトロント、ロングビーチ、リッチモンドを挙げ、こう結びます。「アン、ロイス、ケイティが、はるか昔にその考えの種をまき、それがその後、何百ものアラノン家族グループとして花開いたことは確かである」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。同じ本の写真の説明文は、アクロンのスミス家が、「ロイスとアンが、いつか家族グループと呼ばれることになるものの土台を築いた」場所だと述べています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

『ドクター・ボブと古き良き仲間たち』（1980年）は、1935年の夏、アン・スミスの招きで初めてアクロンを訪れたときのロイス自身の記憶を付け加えています。「アンは、私が同じアルコホーリクの妻として心を通わせられる人だった」（『ドクター・ボブと古き良き仲間たち』、1980年）。アラノンの現在の形を1951年とし、「ただし、AAメンバーの親族からなる『家族グループ』は、それ以前の数年のうちに育ってきていた」（『ドクター・ボブと古き良き仲間たち』、1980年）と述べ、アラノンとアラティーンは「AAとはまったく別のもの」だとしています（『ドクター・ボブと古き良き仲間たち』、1980年）。ビッグブック自身の後の注記も同じことを述べています。アラノンは「妻たちへ」が書かれてからおよそ13年後に生まれ、「アルコホーリクス・アノニマスとはまったく別のもの」だというのです（英語版121ページ）。

『Pass It On』（1984年）には、ロイス自身が後に語った転機が載っています。ある日曜日、ビルがオックスフォード・グループの集まりに遅れると言ったとき、彼女はビルに靴を投げつけました（『Pass It On』、1984年）。そして「その日、私は初めて、自分を分析的に見つめ始めた。」（『Pass It On』、1984年）。彼女は、自分ができなかったことを他の誰かが成し遂げたことに憤っていたと気づき、「私は彼の新しい友人たちに嫉妬していた」のです（『Pass It On』、1984年）。

私たちの本のどれにも、ロイスがアラノンを創設したと、そのままの言葉では書かれていません。示されているのは、彼女がその考えの種をまく手助けをし、それを初期のグループに持ち込み、1955年に家族グループを代表して話した、ということです。次もご覧ください：アラノンはAAの一部ですか？

1955年、セントルイスで

大会の閉会のセッションで、ビルは母親とロイスとともに舞台に座りました。ロイスは「希望が失われたときも、揺るがず耐え抜いた人であり、私の第二の誕生に立ち会った人」です（『アルコホーリクス・アノニマス 成年に達する』、1957年）。常任理事会の議長だったバーナード・スミスは、彼女を「私たち皆にとって、AAの妻の象徴」と紹介しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

全文が載っている彼女の講演は、家族に代わって語っています。メンバーたちに感謝して、「私個人に、そしてAAの他のすべての妻と夫に、より良く、より役に立つ人生へ至る道を示してくれた」ことを挙げ（『アルコホーリクス・アノニマス 成年に達する』、1957年）、家族グループを「切実な必要への自然な応答」と述べます（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「私たちもまた、アルコールに対し無力であることを認める。私たちは、あなた方の問題から手を離そうとしている。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。彼女は数字を挙げます。1950年のクリーブランド大会の時点では家族グループはおそらく100に満たなかったが、1955年には700近くになったというのです（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビルによれば、大会の前半で、ロイスなどの講演者が、家族グループには独自の世界的な情報センターと独自の文献があることをAAメンバーに伝えました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。次もご覧ください：1955年のセントルイス大会では何があったのですか？

資料が食い違う点、あるいは決着をつけていない点

  • 「妻たちへ」。『ドクター・ボブと古き良き仲間たち』（1980年）によれば、ビルは妻たちのための章をアン・スミスに書くよう提案し、ロイスは「頼まれず」、自分が申し出ると、ビルは本と同じ文体にするべきだと言いました（『ドクター・ボブと古き良き仲間たち』、1980年）。同書は、数十年後の彼女の言葉を引いています。「私はずっとそれに傷ついてきた」（『ドクター・ボブと古き良き仲間たち』、1980年）。ビル自身の1957年の本には、このことは出てきません。
  • アラノンを創設した人。上に述べたとおり、1957年の記述はアン、ロイス、ケイティがその考えの種をまいたとし、1980年の本は、アラノンの現在の形を1951年としています。私たちの資料には、アラノン自身のものはありません。『Lois Remembers』は彼女自身の本で、アラノンから出版されており、資料の一覧に名前が挙がっているだけです（『Pass It On』、1984年）。
  • 彼女の死。1988年という年は、のちの刷りにある年表からのものです。1957年と1984年の文章は、彼女が存命のあいだに書かれました。

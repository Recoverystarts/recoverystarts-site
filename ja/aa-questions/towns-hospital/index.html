タウンズ病院で、ビル・Wに何が起きたのですか？

このページのAAの文献からの引用のうち、12のステップ、12の伝統（短いものと長文のもの）、12の概念の短いかたち、AAの序文は、AA日本ゼネラルサービス（JSO）が公開している日本語です。ビッグブックの本文、祈り、12の概念の長いかたち、そのほかのAAの文献や歴史書からの引用の日本語は、AAの英語の原文からの私たちの翻訳で、AAが出版した日本語訳ではありません。英語で読む

ひとことで言うと：

  • ニューヨークのタウンズ病院は、ウィリアム・D・シルクワース医師が担当医を務めていたところで、ビル・Wを何度か治療しました。1934年12月の最後の入院の際、友人エビーの訪問から数週間後、ビルは飲酒を終わらせた突然の霊的体験をしました。
  • 1939年のビッグブックは、それを静かに語っています。病院で、彼は自分を神に差し出し、自分の罪を取り去ってもらう気持ちになり、平安と、「山頂の大きな清らかな風」が自分のなかを吹き抜けるのを感じました。彼は医師に、自分はまだ正気かと尋ね、医師は、理解できないことが起きたが、ビルはそれにしがみついているほうがいいと答えました。
  • ビルののちの記述には、絶望の叫び（「もし神がいるなら、姿を現してくれ！」）、白い光に照らされた部屋、そして存在の感覚が加わります。医師の安心させる言葉も、違う言葉で伝えています。
  • ビッグブックに収められたシルクワース自身の手紙は、AAにつながった考えが、この患者に「3度目の治療の過程で」訪れたと述べています。

1939年のビッグブック

「ビルの物語」。以前の入院は「アルコホーリクの精神的・身体的なリハビリテーションのための、全国的に知られた病院」（英語版7ページ）でのことでした。「いわゆるベラドンナ療法のもとで、私の頭は晴れた。」（7ページ）そして親切な医師が、彼が身体も精神も重い病気だったことを説明しました（7ページ）。彼はまた飲み、また病院に戻り、妻は、彼が1年以内に死ぬか、気が狂うと告げられました（7ページ）。

エビーの訪問のあと、彼はもう一度病院に戻りました。「その病院で、私はこれを最後にアルコールから切り離された。」（英語版13ページ）「そこで私は、そのときに理解していた神に、御心のままに私を用いてくださるよう、謙虚に自分をささげた。」（13ページ）友人が訪ねてきて、二人でビルが傷つけた人たちの表を作りました（13ページ）。ビルがこれらの提案を完全に受け入れたとき、「その効果は電撃的だった。勝利の感覚があり、続いて、それまで知らなかったほどの平安と静けさが訪れた。」（14ページ）「私は高く持ち上げられたように感じた。まるで山頂の大きな清らかな風が、私の中を吹き抜けていくようだった。」（14ページ）「神はたいていの人のところに少しずつやって来るが、私に対するその衝撃は突然で、深いものだった。」（14ページ）

驚いた彼は、自分はまだ正気かと医師に尋ねました。医師は言いました。「あなたに、私には理解できないことが起こった。しかし、それを手放さないほうがいい。」（英語版14ページ）まだ病院にいる間に、ビルは、自分が助けられるかもしれない何千人もの希望のないアルコホーリクのことを思いました（14ページ）。1939年の本文は、病院も医師も名前を挙げていません。名前は、のちの記述から来ています。

「医師の意見」。シルクワース医師の手紙も1939年のもので、ビルの名は出てきません。「1934年の終わり近く、私はある患者を診た。彼は有能な実業家で収入も十分にあったが、私が見込みがないと考えるようになっていた類のアルコホーリクだった。」（xxvページ）「3回目の治療の間に、彼は回復の可能な手段についてある考えを得た。」（xxvページ）「医師の意見」とは何で、誰が書いたのですか？を参照してください。

ビルののちの記述（1957年、および1984年に語られたもの）

『アルコホーリクス・アノニマス 成年に達する』（1957年）。1934年の夏、ビルはタウンズに横たわり、シルクワース医師はロイスに、彼は見込みがないと告げました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。12月、エビーの訪問とカルバリー・ミッションでの一夜のあと、彼はビールの瓶を持ってタウンズに入りました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「3、4日で、彼らがわずかに与えた鎮静剤の影響から抜けた」（『アルコホーリクス・アノニマス 成年に達する』、1957年）が、ひどく落ち込み、神という考えをまだ受け入れられずにいました。エビーが来て、彼の方式を繰り返しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。そして、穴の底で、彼は叫びました。「もし神がいるなら、姿を現してくれ！私は何でもする、何でも！」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。部屋は大きな白い光に満たされ、彼は霊の風が吹く山の上にいるように感じ、自分は自由な人間だと感じました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「これが説教師たちの言う神か！」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

幻覚を見ているのではと怖くなり、彼は医師を呼びました。医師は言いました。「いや、ビル、あなたは気が狂ってなどいない。」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。同じ本の別の箇所で、ビルは医師の言葉を「あなたは幻覚を見ているのではない」（『アルコホーリクス・アノニマス 成年に達する』、1957年）と引いています。ビルの記憶では、翌日、エビーがウィリアム・ジェームズの『宗教的経験の諸相』を持ってきて、それが何が起きたのかを理解する助けになりました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。ビッグブックはなぜウィリアム・ジェームズに触れているのですか？もご覧ください。

P-53（ビルの略伝、パンフレットは© 2017）：エビーがメッセージを運んでから1か月後のタウンズ病院で、「完全な絶望のなか、彼は助けを求めて叫んだ」（P-53）。この体験は、解き放たれたという確信と、ほかのアルコホーリクを助けることが自分を飲まずにいさせてくれるという洞察をもたらしました（P-53）。

『Pass It On』（1984年）は、彼の入院を1934年12月11日とし、当時の治療は鎮静のためのバルビツール酸系薬剤とベラドンナだったと述べています（『Pass It On』、1984年）。叫びは「もし神がいるのなら、姿を現してくれ！」（『Pass It On』、1984年）、シルクワースの答えは「そうだよ、若いの、あなたは正気だ。私の判断では完全に正気だ。」（『Pass It On』、1984年）としています。彼は12月18日に退院しました（『Pass It On』、1984年）。本は、1934年を「ビルが4回入院した年」（『Pass It On』、1984年）と呼んでいます。

その後、タウンズが意味したこと

ビルは、シルクワース医師の許可を得て、タウンズ病院に戻って患者たちと関わりました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。「私は何度も絶望して、昔の病院に出かけた。そこで一人の男と話すと、驚くほど気持ちが引き上げられ、再び立ち上がることができた。」（15ページ）第11章には、東部の都市にある、名前の出ていない有名な病院が出てきます。そこでは医師がメンバーに患者を送り、「私たちの多くが、その壁の中で初めて、神の存在と力を感じた。」とあります（162ページ）。のちに、その病院の所有者チャールズ・B・タウンズはビルに有給の非専門家セラピストの職を提示しましたが、ビルは自分のグループが反対したため断りました（『アルコホーリクス・アノニマス 成年に達する』、1957年、『Pass It On』、1984年）。また、タウンズはビッグブックのためにお金を貸しました（『アルコホーリクス・アノニマス 成年に達する』、1957年）。

資料の記述が食い違うところ

  • 体験そのもの。1939年の本文には、叫びも、光も、「存在」もありません。そこにあるのは、謙虚な降伏、そのあとの勝利の感覚、平安、山の風です（13～14ページ）。叫びと白い光は、ビルの1957年の記述とそれ以降にあります（『アルコホーリクス・アノニマス 成年に達する』、1957年、『Pass It On』、1984年）。叫びの言葉づかいは、それらの間で少し異なります。
  • 医師が言ったこと。1939年：自分には理解できないことが起こった、それを手放さないほうがいい（14ページ）。1957年：「あなたは正気を失っていない」、そして、そのような出来事について読んだことがあり、それがアルコホリズムから人を解き放つことがあるのだと（『アルコホーリクス・アノニマス 成年に達する』、1957年）、あるいは別の箇所では「あなたは幻覚を見ているのではない」（『アルコホーリクス・アノニマス 成年に達する』、1957年）。1984年：「あなたは正気だ、まったく正気だ」（『Pass It On』、1984年）。
  • どの入院のときか。シルクワースの1939年の手紙は、その考えは患者の「3回目の治療」の間に得られたと述べていますが（xxvページ）、『Pass It On』は、ビルは1934年に4回入院したと述べています（『Pass It On』、1984年）。私たちの資料は、この回数を調整していません。
  • 薬。『Pass It On』は、当時の治療としてバルビツール酸系薬剤とベラドンナを挙げています（『Pass It On』、1984年）。ビル（1957年）は、体験の前に、3、4日で鎮静剤の影響から抜けたと述べています（『アルコホーリクス・アノニマス 成年に達する』、1957年）。私たちの資料は、治療と体験のあいだに関連づけていません。

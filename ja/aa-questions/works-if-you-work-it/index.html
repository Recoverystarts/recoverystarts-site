英語の「it works if you work it」（やればうまくいく）は、ビッグブックにありますか？

このページのAAの文献からの引用のうち、12のステップ、12の伝統（短いものと長文のもの）、12の概念の短いかたち、AAの序文は、AA日本ゼネラルサービス（JSO）が公開している日本語です。ビッグブックの本文、祈り、12の概念の長いかたち、そのほかのAAの文献や歴史書からの引用の日本語は、AAの英語の原文からの私たちの翻訳で、AAが出版した日本語訳ではありません。英語で読む

ひとことで言うと：

  • この言葉そのものは、1939年のプログラム本文にも、私たちの資料のほかのどこにも、その形ではありません。ビッグブック全体で最も近い言葉は、第4版の体験談の、恨みを抱いている相手のために祈ることについての箇所です。「私がそれに取り組む気持ちのあるときはいつでも、それは私にとってうまくいく」（英語版552ページ）。
  • プログラム本文でいちばん近い言葉は、祈りについてです。「適切な態度でそれに取り組むなら、それはうまくいく」（英語版86ページ）。2ページあと、同じ毎日の実践の終わりに：「それはうまくいく――本当にうまくいく」（88ページ）。
  • 本文はほかにも、同じ精神で約束をしており、それぞれ具体的なことについてです。第6章の約束は「私たちが努力するなら、それは必ず実現する」（英語版84ページ）、そして、ほかのアルコホーリクとの活動は「ほかの活動が失敗するときにもうまくいく」（89ページ）。
  • 第5章にある、ほかの多くの「どうやればうまくいくのか」という行は、そのページの上部に印刷された章の題名にすぎません。

検索の結果

私たちが持つすべての資料で、「works if you work」「if you work it」「work it」「it works」「work at it」「really works」を検索しました。

その言い回しそのものは見つかりません。第5章の「HOW IT WORKS」は、1ページおきの上部に印刷される柱（ページの上部に印刷される見出し）であって、文ではありません。

プログラム本文のなかで、何かが「うまくいく」と述べられている箇所：

  • ビルが、落ち込んでいたときにほかのアルコホーリクと関わったことについて：「それは、困難な状況でもうまくいく生き方の設計図である」（英語版15ページ）。
  • 第2章：私たちに新しい生活が与えられた、あるいはそう呼びたければ、「本当にうまくいく」「生き方の設計図」（英語版28ページ）。
  • 第6章、約束：「私たちが努力するなら、それは必ず実現する」（英語版84ページ）
  • 第6章、ステップ11：祈りは「適切な態度でそれに取り組むなら、うまくいく」（英語版86ページ）。
  • 第6章、ステップ11の終わり：「それはうまくいく――本当にうまくいく」（英語版88ページ）。
  • 第7章、冒頭：ほかのアルコホーリクとの徹底した活動は、「ほかの活動が失敗するときにもうまくいく」（英語版89ページ）。

体験談では、第4版のある書き手が、こう締めくくっています。「うまくいくから、私は通い続けている」（374ページ）。もう一人、「束縛からの自由」（第3部）の書き手が、この言葉にいちばん近い表現を述べています。彼女は、聖職者の記事が勧めたとおり、恨んでいた相手のために毎日祈ることで、恨みから解放されたことを述べ、こう言います。「そのときも私にとってうまくいったし、それ以来何度もうまくいってきた。そして、私がそれに取り組む気持ちのあるときはいつでも、うまくいくだろう。」（552ページ）プログラム本文自身の最も近い一文（86ページ）と同じく、それは祈りという特定の実践についてであり、のちの版の一人のメンバーの言葉で、プログラム本文ではありません。『Pass It On』（1984年）は、この本を出版するために作られた会社ワークス出版社の名前は、メンバーに人気のスローガン「うまくいく！」（It works!）にちなんでいると考えたメンバーもいた、と述べています（『Pass It On』、1984年）。「行いのない信仰は死んだものである」から来ていると言う人もいました。

最も近い一文を、文脈のなかで読む

英語版86ページの一文は、本のステップ11についての指示の最初にあります。「祈りについて、遠慮する必要はない。私たちよりも立派な人たちが、絶えずそれを使っている。適切な態度でそれに取り組むなら、それはうまくいく」（85～86ページ）。「それ」とは祈りです。本は続けて、その取り組みが具体的に何であるかを述べます（86～88ページ）。

  • 夜、その日を振り返ります。恨み、利己心、不正直、恐れはなかったか。謝るべきことはないか。ほとんどの時間、自分のことを考えていなかったか、「それとも、他の人のために何ができるかを考えていただろうか」（英語版86ページ）。そして神に赦しを求め、正すべきことを尋ねます。
  • 目覚めたとき、これからの一日について考え、神に、私たちの考えを導いてくださるよう、特に、自己憐憫や不正直で利己的な動機から離れているよう求めます（英語版86ページ）。
  • 何をすべきか迷ったときは、ひらめきを求め、力を抜き、「もがかない」ようにします（英語版86ページ）。
  • 朝の黙想は、一日をとおして次の一歩を示してほしいと求めて終え、「自分自身の利己的な目的のために祈ることは決してしない」よう気をつけます（英語版87ページ）。
  • 日中、気持ちが乱れたり迷ったりしたら立ち止まり、正しい考えや行動を求め、一日に何度も「あなたの意志が行われますように」と言います（英語版87～88ページ）。

そして：「それはうまくいく――本当にうまくいく」（英語版88ページ）。続く数行は、これがすべてではないと述べています。「行動、そしてさらに行動がある」（88ページ）、そして次の章は、メッセージを運ぶことについてです。

つまり、本が言い回しに最も近づくのは、一つの日々の実践、すなわち祈りと自分を省みることについての約束で、条件がはっきり書かれています：「正しい態度」と、それに取り組むこと。

この言い回しが言い当てていること、言い落としていること

結果は取り組むことにかかっているという考えは、本文全体を貫いています。約束は「私たちが努力するなら、それは必ず実現する」（英語版84ページ）。ステップについての章は、書き手たちが、「私たちの道を徹底してたどった人が失敗するのを、私たちはほとんど見たことがない」（58ページ）と述べて始まり、「中途半端なやり方では、何も得られなかった」（59ページ）と述べます。

短いスローガンが言い落としているのは、本文が結果の源として挙げているものです。第6章は、酒に対する新しい態度は「私たちの側の思いも努力もなしに、私たちに与えられた」（英語版85ページ）ものであり、それは「霊的に良い状態を保っているかぎり」（85ページ）続く、と述べています。第5章は、信仰が「私たちが自分ではできなかったことを、私たちのためにしてくれた」と述べています（70～71ページ）。本の中では、メンバーが取り組み、その取り組みが、変化が与えられる状態に彼をとどめているのです。
